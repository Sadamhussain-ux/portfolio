The problem

Six websites from one brief can't all look the same.

In Open Weaver Studio, a user types a business name and a short description, and Studio generates six single-page websites to choose from. If those six share one colour scheme, the user is really choosing between layouts, not looks.

We needed a theme system where each generated website could feel different (calm, bold, premium, playful) without breaking the components underneath or making text hard to read. And users had to be able to change it afterwards.

The system

Every colour comes with its own text colour.

The core idea: colours never travel alone. Each brand colour is mapped to the text colour that sits on top of it, so any component can switch theme without anyone re-checking every button and banner.

Shared meaning

Error, Info, Caution and Success stay the same in all 57 themes, so a warning always looks like a warning.

Surfaces

Lighter and darker versions, from the same palette.

Instead of only white or black pages, each theme chooses a background and foreground preset: Light, Dark, Primary Light, Primary Dark, Secondary Light or Secondary. That gives tinted and deep surfaces that still belong to the brand. Here's the current theme in each preset:

Beyond colour

A theme is a whole personality.

Colour alone wasn't enough to make six websites feel different. Each theme also sets a heading and body font pair, font weights for display, headings and buttons, and widget styles: shadow, border and corner radius.

Organisation

Tagged by mood, not just by colour.

57 themes are hard to manage as a flat list. Every theme is tagged with a mood cluster and a theme family, so themes can be matched to the kind of business, from a clinic to a coffee shop to a law firm.

Make it yours

Start from a theme, then customise it.

Users aren't locked in. From the App Theme panel they can switch to any Studio theme, or open My Custom Theme and set their own primary and secondary colours, base text size, default font, background and foreground presets, and widget styles.

Because components read from the token pairs, a user's custom colours flow through the whole website straight away.

Outcome

What the system made possible.

Real variety

57 themes with their own colours, fonts and widget styles, so the six websites in a set can each look clearly different.

Consistent components

One set of components, many looks. Matched colour and text pairs mean no per-website colour fixing.

User control

Any theme can be the starting point for a custom theme, edited without breaking the design.

My role

  • Defined the colour mapping: primary, secondary and their text colours, plus per-theme neutrals.
  • Designed the surface presets for lighter and darker backgrounds.
  • Built the theme set, with font pairings, weights and widget styles for each theme.
  • Designed the theme picker and custom theme flow in Studio.

What I'd do next

  • Automatic contrast checks whenever a user picks custom colours, with a suggested fix if text becomes hard to read.
  • Theme analytics: which themes users keep or change, to refine the set.
