SADAM HUSSAIN - PORTFOLIO WEBSITE
=================================

FILES
  index.html               the whole website (HTML + CSS + JS in one file)
  assets/sadam.jpg         your photo, cropped for the site
  assets/sadam-original.jpg   your original full-size photo

TO VIEW
  Double-click index.html to open it in your browser.

BEFORE PUBLISHING - EDIT index.html
  1. Search for "[" to find the 3 placeholder case studies and write your real projects.
  2. Replace the CSS-drawn thumbnails with screenshots of your work:
       <img src="assets/project-1.jpg" alt="..." style="width:100%;height:100%;object-fit:cover">
  3. Set each project's href="#" to your case study link (Behance / Notion / PDF).
  4. Put your LinkedIn and Behance URLs in the Contact section (the two href="#").
  5. Save your resume as assets/Sadam_Hussain_Resume.pdf so "Download CV" works.
  6. Colours: change the values in :root at the top of the <style> block.

FREE HOSTING (pick one)
  - Netlify Drop: go to app.netlify.com/drop and drag this whole folder in.
  - GitHub Pages: upload the folder to a repository, then Settings > Pages.
  - Vercel: import the folder or repository.
